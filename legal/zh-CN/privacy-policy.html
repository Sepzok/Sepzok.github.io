隐私政策

本政策说明 Sepzok（随造，下称「我们」）如何处理与本网站及相关公开页面有关的信息。本政策仅针对公司官网、开源项目介绍页等公开站点，不构成对任何未在本站公开之软件或服务的说明。

1. 适用范围

本政策适用于您访问、浏览我们运营的公开网站（含通过 GitHub Pages 等托管的公司站点）以及您为联系我们而主动提供的信息。若您使用我们在 GitHub 等第三方平台上的公开仓库，该平台自身的隐私政策同时适用。

2. 我们可能收集的信息

  • 您主动提供的信息：当您通过 GitHub Issue、私信或其他您选择的渠道联系我们时，您提交的称呼、联系方式与留言内容。
  • 技术与日志类信息：托管方或内容分发网络可能自动记录访问时间、大致地理位置（如国家/地区）、浏览器类型、设备类型、来源页面与请求路径等，用于站点可用性与安全防护。我们不以此识别您的现实身份。
  • 本地存储：本站可能使用浏览器本地存储保存您选择的界面语言等偏好，此类数据留在您的设备上。

我们目前不在本站部署用于跨站广告追踪的第三方分析像素。若日后引入，将在本政策中更新并说明。

3. 我们如何使用信息

  • 运营、维护与改进公开网站；
  • 回应您的问询、商务或媒体来信、安全报告；
  • 检测、预防滥用、欺诈与安全事件；
  • 遵守适用法律与执法要求。

4. Cookie 与类似技术

本站可能使用必要的本地存储或 Cookie，用于记住语言偏好、保障基本功能。我们不将 Cookie 用于向您展示第三方广告。

5. 共享与披露

我们不会出售您的个人信息。仅在下列情形共享必要信息：

  • 托管、域名、内容分发等服务提供商，且其仅按我们的指示处理；
  • 您明确同意的情形；
  • 法律要求、法院命令或为保护我们及他人的权利、安全与财产。

6. 保存期限

联系类信息在处理完毕后按业务需要合理保存，或按您的删除请求处理（法律要求保留的除外）。托管与安全日志按其服务商默认周期轮转。

7. 安全

我们采取与公开站点风险相适应的合理措施（如 HTTPS、访问控制与依赖更新）。互联网传输无法保证绝对安全；发现安全问题的报告方式见安全页。

8. 跨境与托管位置

本站可能由位于不同国家和地区的基础设施托管。访问本站即可能使相关技术数据在相关司法辖区处理。若您通过 GitHub 联系我们，数据还将受 GitHub 服务条款与隐私政策约束。

9. 您的权利

在适用法律允许的范围内，您可请求查阅、更正或删除您主动提供给我们的联系信息，或就本政策提出疑问。请通过联系页所述渠道与我们联络。我们可能需要核实请求人身份。

10. 儿童

本站面向一般公众与企业访客，不面向儿童主动收集个人信息。若您认为我们误收了儿童信息，请联系我们以便删除。

11. 政策更新

我们可能不时更新本政策。重大变更将更新文首版本日期；继续使用本站即表示您知悉更新后的政策（法律另有要求的除外）。

12. 联系我们

隐私相关问询请见联系页，或通过 github.com/Sepzok 留言并在标题标明「Privacy」。
